# Tamim CCTV APK build

This project is ready to build a debug APK using GitHub Actions.

1. Create a new GitHub repository.
2. Upload the contents of this project to the repository.
3. Open the **Actions** tab and run **Build Tamim CCTV APK**.
4. When the workflow finishes, open the run and download the **Tamim-CCTV-APK** artifact.
5. Inside the downloaded artifact is `app-debug.apk`.

No Android Studio is required for this method.
