# Tamim CCTV & Security — Professional Android App

This version redesigns the Home screen in a dark navy/red professional CCTV style.

Included:
- TAMIM CCTV & SECURITY logo in the app UI
- TAMIM logo as the Android launcher icon
- Owner portrait in the Home hero section
- CCTV / Service / Networking / Access Control / Products / Gallery / Location / Contact tiles
- Services section and bottom navigation
- Working Call, WhatsApp, Website and Facebook actions
- Android 7.0+ support (minSdk 24)

## Build

The included GitHub Actions workflow builds a debug APK automatically.

1. Upload this project to a GitHub repository.
2. Open **Actions** → **Build Tamim CCTV APK**.
3. Run **Run workflow** (or push to `main`).
4. Download the artifact named **Tamim-CCTV-APK**.

The generated file is `app-debug.apk`.
